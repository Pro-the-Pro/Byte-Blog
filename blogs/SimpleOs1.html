Title: Simple Os Blog 1

Date: 7/12/2025

This is my first blog about simple os. Simple Os is my own operating system desighned to teach poeple how to use CLI's (Command Line Interfaces) and basic operating system concepts.

Simple Os is still in the very early stages of development but I will be posting updates on Byteblog. Currently Simple Os only has a basic command line nano like text editor and a very buggy calculator app but in in futre Im hoping to add a Simple Html parser and a bitmap image viewer ect.

You can find the GitHub repository for Simple Os here.

Stick around for more Simple Os blogs in the future!
